Fix: Extension Won't Load

The extension shows as installed and enabled, but its features don't work. Commands aren't in the palette. Here's how to diagnose in 2 minutes.

Last updated: October 2026

⚡ The 30-second fix

Open the Command Palette (Ctrl+Shift+P) and run Developer: Show Running Extensions.

This shows every extension currently active. If yours isn't in the list, it failed to activate. Click the extension to see its activation error — that error tells you exactly what's wrong.

The 5 real causes

1

Extension host crashed

One extension crashing can take down the entire extension host — every extension stops working. This is the most common cause of "extension not loading."

Check: Bottom status bar — does it show "Extension host not responding"?

Find the culprit:

# Open the Extension Logs folder
Command Palette → "Developer: Open Extension Logs Folder"

# Look at the most recent log file
# The last extension mentioned before the crash is your culprit

Fix: Disable the crashing extension via the Extensions panel. Reload window. Re-enable only if you can update it or find an alternative.

Note: VS Code auto-disables extensions that crash repeatedly. If yours keeps getting disabled without warning, that's a signal.

2

Version incompatibility

The extension requires a newer VS Code version than you have, or it's built for older APIs you don't run anymore.

Check:

  1. Open the extension's page in the marketplace
  2. Look at "Requires VS Code" version
  3. Compare with your VS Code version (Command Palette → "About")

Fix: Update VS Code, or downgrade the extension to an older version that supports your VS Code.

// In the Extensions panel:
// 1. Find the extension
// 2. Click the gear icon
// 3. Select "Install Another Version..."
// 4. Choose a version compatible with your VS Code
3

Corrupted install

The extension files exist but are incomplete or damaged. Happens after interrupted installs or disk issues.

Symptoms: The extension shows in the list but its description is empty, or it lacks an icon, or its features are missing but no error appears in the Running Extensions panel.

Fix — reinstall cleanly:

# 1. Uninstall via Extensions panel
# 2. Restart VS Code completely
# 3. Reinstall from the marketplace

# Or delete the folder directly:
# macOS/Linux:
rm -rf ~/.vscode/extensions/[publisher].[extension-name]-*

# Windows:
# Delete %USERPROFILE%\.vscode\extensions\[publisher].[extension-name]-*

# Then reinstall via Extensions panel
4

Activation event hasn't fired yet

Extensions only "activate" when a trigger event happens. A Markdown extension won't activate until you open a Markdown file. A Python extension won't activate until you open a Python file.

Check the extension's activation events on its marketplace page or its package.json. Common events:

  • onLanguage:python — activates when a Python file opens
  • onCommand:ext.someCommand — activates when a specific command is called
  • workspaceContains:**/.git — activates only in git repos
  • * — activates immediately (rare, discouraged)

Pro tip: Open the exact file type the extension is designed for. If it activates only on Python files and you have a JS file open, it looks broken but is working as intended.

5

Silent crash or error on activate

The extension tries to activate but immediately throws an error. VS Code logs it but doesn't always notify you.

Read the logs:

Command Palette →
  "Developer: Open Extension Logs Folder"

# Look for the newest log file (usually exthost.log)
# Search for your extension's identifier
# Stack traces there tell you exactly what failed

Common activation errors:

  • Cannot find module 'X' — extension wasn't installed completely
  • ENOENT: no such file or directory — extension expects a file that doesn't exist
  • Permission denied — extension can't read/write the file it needs
  • Extension host terminated unexpectedly — the process itself died

The debugging workflow

  1. Open the running extensions panel — is the extension listed? If not, it's not activating.
  2. Check the Extension Logs folder — what does the log say about your extension?
  3. Verify activation events — have you opened the file type it targets?
  4. Check version compatibility — does your VS Code version meet the minimum?
  5. Reinstall the extension — clean uninstall + reinstall + reload.
  6. Test in a fresh profile — Command Palette → "Developer: Reload Window with Extensions Disabled" to confirm it works in isolation.
  7. Report on GitHub if it's a real bug — extension authors check their issues regularly.

The nuclear option: profile reset

If extensions are misbehaving in ways that resist all other fixes, reset VS Code to a clean state without losing your settings.

# Command Palette → "Developer: Reload Window with Extensions Disabled"
# This loads VS Code without ANY extensions — proves whether it's an extension issue

# If you confirm it's an extension issue, isolate with Extension Bisect:
# Command Palette → "Help: Start Extension Bisect"

# For a complete reset (LAST RESORT — back up first):
# macOS:   ~/Library/Application Support/Code/User/
# Linux:   ~/.config/Code/User/
# Windows: %APPDATA%/Code/User/

# Move the "User" folder elsewhere, restart VS Code.
# You'll lose settings, keybindings, and snippets — but extensions reset clean.

Back up first. Settings Sync can restore your configuration after a reset. Otherwise, copy the folder before deleting.

🛡️ How to keep extensions reliable

  • Update VS Code regularly. Extension compatibility improves with each release.
  • Don't install extensions you don't use. Every extension is a potential source of conflicts and crashes.
  • Prefer popular, maintained extensions. 100K+ installs and recent updates are strong signals.
  • Watch for auto-disable notifications. VS Code disabling an extension means it's been crashing.
  • Use Extension Bisect when something breaks. Don't guess — let VS Code tell you.
  • Keep a "known good" list. Write down your working extensions. When things break, you can compare.

❓ Frequently asked questions

Why won't my VS Code extension load?

Most common causes: the extension is incompatible with your VS Code version, the extension host crashed, the extension files are corrupted, or an 'Activation Events' rule prevents it from starting until a specific trigger. Check the Extension Logs folder for the exact error.

How do I check if an extension is actually running?

Open the Command Palette (Ctrl+Shift+P) and run 'Developer: Show Running Extensions'. This shows a list of all extensions currently active, their activation time, and any that failed to activate.

What does 'Extension host terminated unexpectedly' mean?

The process running all extensions crashed. Usually one extension is crashing the entire host. Check the Extension Logs folder for the last extension mentioned, then disable it.

How do I reinstall a corrupted VS Code extension?

Uninstall the extension via the Extensions panel, restart VS Code, then reinstall from the marketplace. Or delete the extension's folder from ~/.vscode/extensions/ (macOS/Linux) or %USERPROFILE%/.vscode/extensions/ (Windows).

Why is my extension disabled without my input?

VS Code disables extensions that crash repeatedly for safety. Look for a notification about it. Re-enable via the Extensions panel, or fix the underlying issue before re-enabling.
