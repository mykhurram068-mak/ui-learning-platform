📝 LocalStorage Note Vault

Build a fast, searchable sticky-note vault with color-coded tags, pin-to-top sorting, one-click copy, and automatic browser storage using JSON and localStorage.

Last updated: November 2026 · 7 min read

A LocalStorage Note Vault stores user notes directly inside the browser using JSON.stringify() and localStorage.setItem(). No backend server, no database setup, and zero signup required.

What you will build: A responsive note manager featuring instant keyword search, 4 tag filters (Code, Ideas, Tasks, Urgent), pin-to-top priority sorting, XSS-safe rendering, and full standalone source code.

        <button class="filter-btn" data-filter="Tasks">Tasks</button>

  <script>
    const STORAGE_KEY = 'makui_note_vault_v1';
    let activeFilter = 'All';
    let searchQuery = '';

    const starterNotes = [
      { id: 1, title: 'CSS Grid Responsive Cards', tag: 'Code', content: 'grid-template-columns: repeat(auto-fill, minmax(280px, 1fr));', pinned: true, date: 'Starter' },
      { id: 2, title: 'Weekend Project Idea', tag: 'Ideas', content: 'Build a Pomodoro timer with SVG progress rings and audio alerts.', pinned: false, date: 'Starter' }
    ];

    function loadNotes() {
      try {
        const raw = localStorage.getItem(STORAGE_KEY);
        return raw ? JSON.parse(raw) : [...starterNotes];
      } catch {
        return [...starterNotes];
      }
    }

    let notes = loadNotes();

    function saveNotes() {
      localStorage.setItem(STORAGE_KEY, JSON.stringify(notes));
      renderNotes();
    }

    function escapeHTML(str) {
      return str.replace(/[&<>"']/g, m => ({ '&':'&amp;', '<':'&lt;', '>':'&gt;', '"':'&quot;', "'":'&#39;' }[m]));
    }

    function renderNotes() {
      const grid = document.getElementById('notesGrid');
      const filtered = notes
        .filter(n => activeFilter === 'All' || n.tag === activeFilter)
        .filter(n => n.title.toLowerCase().includes(searchQuery) || n.content.toLowerCase().includes(searchQuery))
        .sort((a, b) => Number(b.pinned) - Number(a.pinned) || b.id - a.id);

      document.getElementById('noteCount').textContent = `${filtered.length} Note${filtered.length === 1 ? '' : 's'}`;

      if (!filtered.length) {
        grid.innerHTML = '<div class="empty-state">No matching notes found. Add one above!</div>';
        return;
      }

      grid.innerHTML = filtered.map(note => `
        <article class="note-card" data-tag="${escapeHTML(note.tag)}">
          <div class="note-top">
            <span>${note.pinned ? '📌 Pinned · ' : ''}${escapeHTML(note.tag)}</span>
            <span>${escapeHTML(note.date)}</span>
          </div>
          <h2 class="note-title">${escapeHTML(note.title)}</h2>
          <p class="note-body">${escapeHTML(note.content)}</p>
          <div class="note-actions">
            <button class="icon-btn" onclick="togglePin(${note.id})">${note.pinned ? 'Unpin' : 'Pin'}</button>
            <button class="icon-btn" onclick="copyNote(${note.id}, this)">Copy</button>
            <button class="icon-btn" onclick="deleteNote(${note.id})">Delete</button>
          </div>
        </article>
      `).join('');
    }

    document.getElementById('noteForm').addEventListener('submit', e => {
      e.preventDefault();
      const title = document.getElementById('noteTitle').value.trim();
      const tag = document.getElementById('noteTag').value;
      const content = document.getElementById('noteContent').value.trim();
      if (!title || !content) return;

      notes.unshift({
        id: Date.now(),
        title,
        tag,
        content,
        pinned: false,
        date: new Date().toLocaleDateString()
      });
      e.target.reset();
      saveNotes();
    });

    document.getElementById('filterGroup').addEventListener('click', e => {
      if (!e.target.matches('.filter-btn')) return;
      document.querySelectorAll('.filter-btn').forEach(b => b.classList.remove('active'));
      e.target.classList.add('active');
      activeFilter = e.target.dataset.filter;
      renderNotes();
    });

    document.getElementById('searchInput').addEventListener('input', e => {
      searchQuery = e.target.value.toLowerCase().trim();
      renderNotes();
    });

    window.togglePin = id => {
      notes = notes.map(n => n.id === id ? { ...n, pinned: !n.pinned } : n);
      saveNotes();
    };

    window.copyNote = (id, btn) => {
      const note = notes.find(n => n.id === id);
      if (!note) return;
      navigator.clipboard.writeText(note.content);
      btn.textContent = 'Copied!';
      setTimeout(() => { btn.textContent = 'Copy'; }, 1500);
    };

    window.deleteNote = id => {
      notes = notes.filter(n => n.id !== id);
      saveNotes();
    };

    renderNotes();
  </script>
</body>

🧱 How It Works (6-Step Architecture)

Understand the core browser APIs powering this app without any external libraries.

1. State-Driven Rendering

Instead of manually appending or removing individual DOM cards when a user adds or deletes a note, we keep a single JavaScript array (notes) as the source of truth and re-render the grid cleanly via renderNotes().

2. JSON Serialization with localStorage

Browser storage only accepts strings. Every mutation calls localStorage.setItem(STORAGE_KEY, JSON.stringify(notes)). On initial page load, JSON.parse() restores your objects inside a safe try/catch block.

3. Multi-Criteria Filtering & Pin Sorting

Before rendering, we chain .filter() for both the active tag pill and the lowercase search query, then .sort() so pinned notes (Number(b.pinned) - Number(a.pinned)) always float to the top.

4. XSS Protection via Character Escaping

Because developers often paste HTML tags or JavaScript snippets into notes, escapeHTML() converts <, >, and & into safe HTML entities so code displays cleanly without breaking page layout or running scripts.

5. Attribute-Driven Tag Colors

Each card receives data-tag="Code" or data-tag="Urgent". CSS attribute selectors (.note-card[data-tag="Urgent"]) style the top accent border automatically without extra class-mapping logic.

6. One-Click Clipboard API

Using navigator.clipboard.writeText(note.content) lets users copy stored commands or snippets in one click, paired with immediate button text feedback.

⚠️ Common mistakes

  • Saving objects without JSON.stringify(). Browser storage coerces raw arrays into "[object Object]", corrupting your data on reload.
  • Skipping try/catch around JSON.parse(). If stored data is ever corrupted or storage is blocked in private browsing, an uncaught error crashes the entire script.
  • Mutating arrays without re-saving. Updating a note's pinned boolean in memory won't persist unless you call saveNotes() immediately afterward.

❓ Frequently asked questions

How much data can localStorage hold?

Most modern browsers allocate about 5MB per origin for localStorage. For plain text notes and JSON metadata, that is enough to store thousands of entries without a backend database.

Why do we use JSON.stringify() and JSON.parse() with localStorage?

localStorage only stores string key-value pairs. JSON.stringify() converts your array of note objects into a string before saving, and JSON.parse() converts it back into a usable JavaScript array when the page reloads.

How do I prevent XSS attacks when rendering user notes?

Never insert raw user input directly into innerHTML. Always escape special HTML characters (&, <, >, quotes) or use textContent so pasted code snippets render safely as text instead of executing scripts.

Will localStorage notes stay saved if I close the browser?

Yes. Unlike sessionStorage, data saved in localStorage persists across page reloads, tab closures, and browser restarts until the user clears browser site data or deletes the notes.
