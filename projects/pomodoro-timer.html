⏳ Focus Pomodoro Timer

Master setInterval, animated SVG progress rings, synthesized Web Audio chimes, and automatic break cycles in one standalone productivity widget.

Last updated: November 2026 · 40 min build

A Pomodoro timer alternates 25-minute deep focus blocks with 5-minute short breaks, awarding a 15-minute long break after every 4 completed sessions. You can build the entire visual ring and alert chime using native SVG geometry and the browser's Web Audio API—zero external libraries or audio files required.

What you will build: Three-mode switcher (Focus, Short Break, Long Break), smooth stroke-dashoffset circular progress bar, live browser tab countdown title, synthesized 3-note chime, and persistent session tracking in localStorage.

    <script>
        (function() {
            const MODES = {
                focus: { minutes: 25, label: 'Focus Session', isBreak: false },
                short: { minutes: 5, label: 'Short Break', isBreak: true },
                long: { minutes: 15, label: 'Long Break', isBreak: true }
            };

            const CIRCUMFERENCE = 2 * Math.PI * 104; // ~653.45
            let currentMode = 'focus';
            let totalSeconds = MODES.focus.minutes * 60;
            let remainingSeconds = totalSeconds;
            let timerId = null;
            let completedSessions = 0;

            const timeDisplay = document.getElementById('timeDisplay');
            const statusLabel = document.getElementById('statusLabel');
            const progressRing = document.getElementById('progressRing');
            const startPauseBtn = document.getElementById('startPauseBtn');
            const resetBtn = document.getElementById('resetBtn');
            const skipBtn = document.getElementById('skipBtn');
            const modeBtns = document.querySelectorAll('.mode-btn');
            const currentTaskInput = document.getElementById('currentTask');
            const sessionCountText = document.getElementById('sessionCountText');
            const dots = document.querySelectorAll('.dot');
            const resetStatsBtn = document.getElementById('resetStatsBtn');
            const toastEl = document.getElementById('toast');

            // Load saved state
            try {
                completedSessions = parseInt(localStorage.getItem('mak_pomo_sessions') || '0', 10) || 0;
                currentTaskInput.value = localStorage.getItem('mak_pomo_task') || '';
            } catch (e) {}

            function showToast(msg) {
                toastEl.textContent = msg;
                toastEl.classList.remove('show');
                void toastEl.offsetWidth;
                toastEl.classList.add('show');
                clearTimeout(toastEl._t);
                toastEl._t = setTimeout(() => toastEl.classList.remove('show'), 3200);
            }

            // Web Audio API gentle chime (no external MP3 needed)
            function playChime() {
                try {
                    const ctx = new (window.AudioContext || window.webkitAudioContext)();
                    const notes = [523.25, 659.25, 783.99]; // C5, E5, G5
                    notes.forEach((freq, i) => {
                        const osc = ctx.createOscillator();
                        const gain = ctx.createGain();
                        osc.type = 'sine';
                        osc.frequency.setValueAtTime(freq, ctx.currentTime + i * 0.14);
                        gain.gain.setValueAtTime(0.001, ctx.currentTime + i * 0.14);
                        gain.gain.exponentialRampToValueAtTime(0.18, ctx.currentTime + i * 0.14 + 0.03);
                        gain.gain.exponentialRampToValueAtTime(0.0001, ctx.currentTime + i * 0.14 + 0.55);
                        osc.connect(gain);
                        gain.connect(ctx.destination);
                        osc.start(ctx.currentTime + i * 0.14);
                        osc.stop(ctx.currentTime + i * 0.14 + 0.6);
                    });
                } catch (e) {}
            }

            function updateStatsUI() {
                sessionCountText.textContent = completedSessions;
                const cyclePos = completedSessions % 4;
                dots.forEach((dot, idx) => {
                    if (completedSessions > 0 && cyclePos === 0) {
                        dot.classList.add('done');
                    } else {
                        dot.classList.toggle('done', idx < cyclePos);
                    }
                });
            }

            function updateDisplay() {
                const mins = Math.floor(remainingSeconds / 60);
                const secs = remainingSeconds % 60;
                const formatted = `${String(mins).padStart(2, '0')}:${String(secs).padStart(2, '0')}`;
                timeDisplay.textContent = formatted;
                document.title = `${formatted} — ${MODES[currentMode].label} | MAK UI Studio`;

                const fraction = remainingSeconds / totalSeconds;
                const offset = CIRCUMFERENCE * (1 - fraction);
                progressRing.style.strokeDashoffset = offset;
            }

            function stopTimer() {
                if (timerId) {
                    clearInterval(timerId);
                    timerId = null;
                }
                startPauseBtn.textContent = 'Start';
            }

            function switchMode(mode) {
                stopTimer();
                currentMode = mode;
                totalSeconds = MODES[mode].minutes * 60;
                remainingSeconds = totalSeconds;
                document.body.classList.toggle('break-mode', MODES[mode].isBreak);
                modeBtns.forEach(b => b.classList.toggle('active', b.dataset.mode === mode));
                statusLabel.textContent = `Ready • ${MODES[mode].label}`;
                updateDisplay();
            }

            function handleComplete(skipped = false) {
                stopTimer();
                if (!skipped) playChime();

                if (currentMode === 'focus') {
                    if (!skipped) {
                        completedSessions += 1;
                        try { localStorage.setItem('mak_pomo_sessions', String(completedSessions)); } catch (e) {}
                        updateStatsUI();
                    }
                    const nextMode = (completedSessions > 0 && completedSessions % 4 === 0) ? 'long' : 'short';
                    showToast(skipped ? 'Skipped to break' : '🎉 Focus session complete! Time for a break.');
                    switchMode(nextMode);
                } else {
                    showToast(skipped ? 'Skipped to focus' : '⚡ Break over! Ready to focus.');
                    switchMode('focus');
                }
            }

            function toggleStartPause() {
                if (timerId) {
                    stopTimer();
                    statusLabel.textContent = 'Paused';
                    return;
                }
                startPauseBtn.textContent = 'Pause';
                statusLabel.textContent = MODES[currentMode].label;
                timerId = setInterval(() => {
                    remainingSeconds -= 1;
                    updateDisplay();
                    if (remainingSeconds <= 0) {
                        handleComplete(false);
                    }
                }, 1000);
            }

            startPauseBtn.addEventListener('click', toggleStartPause);
            resetBtn.addEventListener('click', () => {
                switchMode(currentMode);
                showToast('Timer reset');
            });
            skipBtn.addEventListener('click', () => handleComplete(true));

            modeBtns.forEach(btn => {
                btn.addEventListener('click', () => switchMode(btn.dataset.mode));
            });

            currentTaskInput.addEventListener('input', () => {
                try { localStorage.setItem('mak_pomo_task', currentTaskInput.value); } catch (e) {}
            });

            resetStatsBtn.addEventListener('click', () => {
                completedSessions = 0;
                try { localStorage.removeItem('mak_pomo_sessions'); } catch (e) {}
                updateStatsUI();
                showToast('Session counter cleared');
            });

            progressRing.style.strokeDasharray = CIRCUMFERENCE;
            updateStatsUI();
            updateDisplay();
        })();
    </script>
</body>

How the timer works (6 steps)

1. SVG Circle Geometry

An SVG <circle> with radius r="104" has a circumference of 2 × π × 104 ≈ 653.45px. Setting stroke-dasharray: 653.45 creates a single dash covering the entire ring, rotated -90deg so countdowns start cleanly at 12 o'clock.

2. Proportional Ring Drain

On every tick, we calculate fraction = remainingSeconds / totalSeconds and set strokeDashoffset = CIRCUMFERENCE * (1 - fraction). CSS transitions smooth out each 1-second step.

3. Safe Interval Lifecycle

A single timerId variable tracks the active setInterval. Clicking Pause, Reset, or switching tabs immediately calls clearInterval(timerId) and sets timerId = null so multiple timers can never stack up.

4. Synthesized Web Audio Chime

Instead of loading external .mp3 assets that might fail offline, playChime() uses AudioContext and three sine-wave oscillators (C5, E5, G5) with exponential gain ramps to produce a gentle notification bell.

5. 4-Session Pomodoro Cycle Logic

When a focus block finishes naturally, completedSessions increments and saves to localStorage. Using modulo arithmetic (completedSessions % 4 === 0), every fourth focus session automatically routes into a 15-minute long break.

6. Live Document Title Sync

Updating document.title on every second lets users monitor remaining focus time directly from their browser tab while coding in another window.

❓ Frequently asked questions

How do you animate an SVG circular progress ring?

Set stroke-dasharray equal to the circle's circumference (2 * Math.PI * radius) and update stroke-dashoffset proportionally to remaining time.

Why use Web Audio API instead of an MP3 file?

Web Audio synthesizes a clean chime directly in the browser with zero external audio files, zero network requests, and no broken file paths.

How do I prevent duplicate timers when clicking Start twice?

Always guard your start function by checking if an interval ID is already active and clear it properly on pause or reset.

Does setInterval drift over long countdowns?

Yes, browser tab throttling can delay setInterval ticks slightly. For high-precision timers, compare Date.now() timestamps against a target end time.
