🔗 Mini URL Shortener

Your first backend bridge: generate custom or random short slugs, store mappings in a JSON file, track click counts, and handle HTTP redirects.

Last updated: November 2026 · 10 min read · ~45 mins build time

A URL shortener maps a short key (like /py42) to a full destination URL. When a visitor opens the short route, Flask looks up the key in links.json, increments its click count, and returns redirect(target_url).

What you learn: Flask GET/POST routes, dynamic URL parameters (<slug>), secrets token generation, safe JSON file persistence, and URL scheme validation.

📦 Complete Flask Application (app.py)

Install Flask with pip install flask, save this code as app.py, and run python app.py.

import json
import os
import re
import secrets
import string
from datetime import datetime
from flask import Flask, abort, redirect, render_template_string, request, url_for

app = Flask(__name__)
DATA_FILE = "links.json"
SLUG_PATTERN = re.compile(r"^[a-zA-Z0-9_-]{3,24}$")


def load_links():
    if not os.path.exists(DATA_FILE):
        return {}
    try:
        with open(DATA_FILE, "r", encoding="utf-8") as f:
            return json.load(f)
    except (json.JSONDecodeError, OSError):
        return {}


def save_links(links):
    with open(DATA_FILE, "w", encoding="utf-8") as f:
        json.dump(links, f, indent=2)


def generate_slug(existing_keys, length=6):
    alphabet = string.ascii_letters + string.digits
    while True:
        slug = "".join(secrets.choice(alphabet) for _ in range(length))
        if slug not in existing_keys:
            return slug


def is_valid_url(url):
    return url.startswith("http://") or url.startswith("https://")

@app.route("/", methods=["GET", "POST"])
def index():
    links = load_links()
    error = None

    if request.method == "POST":
        raw_url = request.form.get("url", "").strip()
        custom_slug = request.form.get("custom_slug", "").strip()

        if not is_valid_url(raw_url):
            error = "Please enter a valid URL starting with http:// or https://"
        elif custom_slug:
            if not SLUG_PATTERN.match(custom_slug):
                error = "Custom alias must be 3–24 characters (letters, numbers, hyphens, underscores)."
            elif custom_slug in links:
                error = f"The alias '{custom_slug}' is already taken. Pick another one."
            else:
                links[custom_slug] = {
                    "url": raw_url,
                    "clicks": 0,
                    "created_at": datetime.utcnow().isoformat() + "Z",
                }
                save_links(links)
                return redirect(url_for("index"))
        else:
            slug = generate_slug(links)
            links[slug] = {
                "url": raw_url,
                "clicks": 0,
                "created_at": datetime.utcnow().isoformat() + "Z",
            }
            save_links(links)
            return redirect(url_for("index"))

    return render_template_string(HTML_TEMPLATE, links=links, error=error)


@app.route("/<slug>")
def follow_slug(slug):
    links = load_links()
    entry = links.get(slug)
    if not entry:
        abort(404)

    entry["clicks"] += 1
    save_links(links)
    return redirect(entry["url"], code=302)


if __name__ == "__main__":
    app.run(debug=True, port=5000)

How the URL Shortener works (6 steps)

1. JSON File Persistence (load_links & save_links)

Instead of requiring a database server on day one, all shortened URLs live inside a human-readable links.json dictionary keyed by slug. Wrapping json.load() in a try/except ensures a missing or empty file never crashes the app.

2. Cryptographically Random Slugs

When the user leaves the custom alias field blank, secrets.choice() builds a 6-character alphanumeric string and loops until it finds one not already present in links.json.

3. Strict Input & Scheme Validation

Before saving any entry, is_valid_url() enforces http:// or https:// prefixes, while SLUG_PATTERN restricts custom aliases to safe URL characters and prevents overwriting routes.

4. Post/Redirect/Get (PRG) Form Flow

After saving a new link on a POST request, Flask immediately returns redirect(url_for("index")). That prevents browsers from resubmitting duplicate links if the user hits Refresh.

5. Dynamic Route & Click Counting (/<slug>)

Flask captures any path segment as slug, looks it up in links.json, increments entry["clicks"] += 1, writes the updated JSON back to disk, and issues an HTTP 302 redirect.

6. Clean 404 Handling for Unknown Slugs

If someone visits a non-existent slug like /unknown123, abort(404) returns a proper HTTP 404 Not Found status instead of throwing a Python KeyError.

⚠️ Common mistakes

  • Allowing arbitrary URL schemes. Without checking for http:// or https://, users can store javascript:alert(1) payloads.
  • Using random instead of secrets. Standard pseudo-random generators are predictable; secrets.choice() is built for tokens and slugs.
  • Forgetting Post/Redirect/Get. Rendering HTML directly after a POST causes duplicate short links when the user refreshes the page.
  • Returning HTTP 301 instead of 302 during testing. Browsers cache 301 Permanent Redirect aggressively, bypassing your Flask server and breaking click tracking on repeat visits.

❓ Frequently asked questions

How does a URL shortener work under the hood?

A URL shortener maps a short alphanumeric code (slug) to a long destination URL in storage. When someone visits /slug, the server looks up the destination, increments a click counter, and returns an HTTP 302 redirect response.

Why use JSON instead of a database for this mini-project?

Storing links in a local links.json file lets you inspect the saved mappings in any text editor and persist data across server restarts without configuring SQLite or PostgreSQL first.

Why use HTTP 302 instead of 301 for click tracking?

HTTP 301 tells browsers to cache the redirect permanently and skip your server on future visits. HTTP 302 (Temporary Redirect) ensures every click hits your Flask route so your analytics stay accurate.

How does the live browser demo work without a Python server?

Because static hosting does not run Python processes, our interactive demo simulates the Flask routing table, click analytics, and redirect preview right inside your browser using localStorage.
