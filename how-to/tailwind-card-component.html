Tailwind CSS Guide

Tailwind CSS Card Component

5 reusable card patterns you'll use on every project.

Last updated: October 2026 · Tested on Tailwind v4.0

Quick answer: A basic Tailwind card is a div with rounded-xl shadow-lg p-6 bg-white. Add space-y-4 for internal spacing, and transition hover:shadow-xl for interactivity. Arrange multiple cards with grid grid-cols-1 md:grid-cols-2 lg:grid-cols-3 gap-6.

1

Basic Card

The foundation. Every other pattern builds on this:

<div class="bg-slate-800 rounded-xl shadow-lg p-6 max-w-sm">
    <h3 class="text-white font-bold text-lg">Card Title</h3>
    <p class="text-slate-400 mt-2">
        This is a basic card with a title and description.
    </p>
</div>
  • rounded-xl — soft corners.
  • shadow-lg — depth.
  • p-6 — internal padding.
  • max-w-sm — caps the width so it doesn't stretch.
2

Card with Image

<div class="bg-slate-800 rounded-xl shadow-lg overflow-hidden max-w-sm">
    <img src="/image.jpg" alt="Card image" class="w-full h-48 object-cover">
    <div class="p-6">
        <h3 class="text-white font-bold text-lg">Card Title</h3>
        <p class="text-slate-400 mt-2">
            Description goes here.
        </p>
    </div>
</div>

overflow-hidden on the card clips the image corners. object-cover on the image keeps the aspect ratio.

3

Clickable Card with Hover Effect

<a href="/post" class="block bg-slate-800 rounded-xl shadow-lg p-6 max-w-sm
    transition-all duration-300
    hover:shadow-xl hover:-translate-y-1 hover:border hover:border-blue-500/50">
    <h3 class="text-white font-bold text-lg">Card Title</h3>
    <p class="text-slate-400 mt-2">Hover over me.</p>
</a>
  • transition-all duration-300 — smooth animation.
  • hover:-translate-y-1 — lifts the card on hover.
  • hover:shadow-xl — deepens the shadow.
4

Profile Card

<div class="bg-slate-800 rounded-xl shadow-lg p-6 max-w-sm text-center">
    <img src="/avatar.jpg" alt="User" class="w-20 h-20 rounded-full mx-auto object-cover">
    <h3 class="text-white font-bold text-lg mt-4">Jane Doe</h3>
    <p class="text-slate-400 text-sm">Frontend Developer</p>
    <div class="flex justify-center gap-3 mt-4">
        <button class="bg-blue-500 hover:bg-blue-600 text-white px-4 py-2 rounded-lg text-sm transition">
            Follow
        </button>
        <button class="bg-slate-700 hover:bg-slate-600 text-white px-4 py-2 rounded-lg text-sm transition">
            Message
        </button>
    </div>
</div>

Note rounded-full for the avatar circle and mx-auto to center it.

6

Card Grid (Responsive)

Arrange any of the above cards in a responsive grid:

<div class="grid grid-cols-1 md:grid-cols-2 lg:grid-cols-3 gap-6">
    <!-- Card 1 -->
    <div class="bg-slate-800 rounded-xl shadow-lg p-6">...</div>
    <!-- Card 2 -->
    <div class="bg-slate-800 rounded-xl shadow-lg p-6">...</div>
    <!-- Card 3 -->
    <div class="bg-slate-800 rounded-xl shadow-lg p-6">...</div>
</div>

1 column on mobile, 2 on tablet, 3 on desktop. This is the standard card grid pattern.

❓ Frequently Asked Questions

How do I make a card in Tailwind CSS?

Use rounded-xl, shadow-lg, and bg-white (or bg-slate-800 for dark mode) on a div. Add p-6 for padding and space-y-4 for internal spacing.

How do I add a hover effect to a Tailwind card?

Use transition-all hover:shadow-xl hover:-translate-y-1 to lift the card on hover. Combine with hover:border-blue-500 for a glowing border effect.

How do I make cards responsive in Tailwind?

Use grid grid-cols-1 md:grid-cols-2 lg:grid-cols-3 gap-6 to arrange cards responsively. Each card is a grid item.

How do I add an image to a Tailwind card?

Add an image at the top of the card with w-full h-48 object-cover. Use rounded-t-xl to match the card's top corners.

Can I make a clickable card in Tailwind?

Yes. Wrap the card in an <a> tag or use group and add hover effects. Use focus-within:ring-2 for keyboard accessibility.
