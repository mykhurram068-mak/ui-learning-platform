☕ How to Install Java

Updated October 2026 · 6 min read · Works on Windows, macOS, and Linux

To install Java, download the **JDK (Java Development Kit)** from a trusted distribution like Eclipse Temurin or Microsoft Build of OpenJDK, run the installer, and verify with java --version. If you're writing Java code, you need the JDK — not just the JRE.

This guide covers installation on Windows, macOS, and Linux, plus setting up JAVA_HOME if a tool asks for it.

Quick answer: For most people, download Eclipse Temurin JDK 21 from adoptium.net. It's free, open source, and works everywhere.

JDK vs JRE vs JVM — What Do You Need?

Java has three related pieces, and knowing the difference saves confusion:

  • JVM (Java Virtual Machine) — the engine that runs compiled Java code.
  • JRE (Java Runtime Environment) — the JVM plus core libraries. Enough to run Java apps.
  • JDK (Java Development Kit) — the JRE plus javac (compiler) and dev tools. Needed to write Java code.

If you're learning Java or building a project, install the **JDK**. If you just need to run a Java app that's already built, the JRE is enough.

Which Java Version Should You Install?

Java releases every 6 months, but only some are LTS (Long Term Support):

  • Java 21 (LTS) — current recommendation, supported until 2031
  • Java 17 (LTS) — older LTS, still widely used
  • Java 11 (LTS) — legacy, used by some enterprise apps
  • Java 8 (LTS) — very old, avoid unless required by an existing project

When in doubt: install Java 21 LTS. Modern frameworks (Spring Boot 3+, Android Studio, Minecraft server tools) all support it.

Installation Guide (Choose Your OS)

🪟 Windows

Step 1
Download the JDK installer

Go to adoptium.net. Click Latest LTS Release. Download the Windows .msi installer for x64 (or ARM64 if you have a Snapdragon PC).

Step 2
Run the installer

Double-click the .msi file. Click Next through the wizard. On the "Custom Setup" screen, click "Set JAVA_HOME variable" and enable it — this saves a manual step later. Also enable "Add to PATH".

Step 3
Verify installation

Open Command Prompt (Win + R → cmd) and run:

$ java --version openjdk 21.0.1 2023-10-17 $ javac --version javac 21.0.1

🍎 macOS

Step 1
Check if Java is already installed
$ java --version

If you see a version number, you're done. If macOS prompts you to install Java, click "More Info" and follow along.

Step 2
Install via Homebrew (recommended)

If you have Homebrew installed:

$ brew install openjdk@21
Step 3
Or download the .pkg installer

From adoptium.net, download the macOS .pkg file. Double-click to install. It handles PATH automatically.

🐧 Linux

Ubuntu / Debian:

$ sudo apt update $ sudo apt install openjdk-21-jdk

Fedora / RHEL:

$ sudo dnf install java-21-openjdk-devel

Arch Linux:

$ sudo pacman -S jdk-openjdk

Verify with java --version and javac --version.

Setting JAVA_HOME (If Needed)

Some tools (Maven, Gradle, Android Studio) look for an environment variable called JAVA_HOME that points to your JDK folder.

On Windows (PowerShell):

PS> [Environment]::SetEnvironmentVariable( "JAVA_HOME", "C:\Program Files\Eclipse Adoptium\jdk-21.0.1.12-hotspot", "Machine" )

On macOS / Linux (add to ~/.zshrc or ~/.bashrc):

# macOS (Homebrew location) export JAVA_HOME=$(/usr/libexec/java_home -v 21) # Linux (Ubuntu example) export JAVA_HOME=/usr/lib/jvm/java-21-openjdk-amd64 export PATH=$JAVA_HOME/bin:$PATH

Then reload your shell:

$ source ~/.zshrc # or ~/.bashrc $ echo $JAVA_HOME

Test Your Installation

Create a file called Hello.java:

// Hello.java public class Hello { public static void main(String[] args) { System.out.println("Java is working! 🎉"); System.out.println("Java version: " + System.getProperty("java.version")); } }

Compile and run:

$ javac Hello.java $ java Hello Java is working! 🎉 Java version: 21.0.1

How Java works: javac Hello.java compiles your source code into bytecode (Hello.class). Then java Hello runs that bytecode on the JVM. That's the two-step process — compile, then run.

Common Installation Errors

"java: command not found"

Your PATH doesn't include Java's bin folder. On Windows, restart your terminal. On macOS/Linux, verify your shell config loads correctly.

"javac: command not found" (but java works)

You installed the JRE instead of the JDK. The JRE can run Java apps but can't compile them. Install the JDK.

"JAVA_HOME is not set"

A tool (Maven, Gradle, Android Studio) needs JAVA_HOME. Follow the section above to set it.

Multiple Java versions installed

Run java --version to see which one is active. To switch on macOS: export JAVA_HOME=$(/usr/libexec/java_home -v 17). On Linux use update-alternatives --config java.

Uninstalling Java

  • Windows: Settings → Apps → find "Eclipse Temurin JDK" → Uninstall
  • macOS: brew uninstall openjdk@21 or delete from /Library/Java/JavaVirtualMachines/
  • Linux: sudo apt remove openjdk-21-jdk

Next Steps

Once Java is installed, the natural next steps are:

  • Install VS Code with the Java extension pack
  • Learn Java basics — variables, classes, objects
  • Build a simple command-line app or Android app
  • Try Spring Boot for backend development

Frequently Asked Questions

What is the difference between JDK, JRE, and JVM?

JVM runs bytecode. JRE = JVM + libraries. JDK = JRE + compiler + tools. Install the JDK for development.

Which Java version should I install?

Install Java 21 LTS. It's the current long-term support version, works with all modern tools, and is supported until 2031.

Do I need to set JAVA_HOME?

Only if a tool asks for it. Most tools detect Java automatically. Set JAVA_HOME for Maven, Gradle, or Android Studio.

OpenJDK or Oracle JDK?

Use OpenJDK — specifically Eclipse Temurin, Microsoft Build of OpenJDK, or Amazon Corretto. All are free for commercial use. Oracle JDK has licensing restrictions.

How do I check if Java is installed?

Run java --version in a terminal. If you see a version, it's installed. If not, you'll get "command not found."

Can I have multiple Java versions installed?

Yes. Java supports parallel installations. Use JAVA_HOME or update-alternatives to switch between them.
