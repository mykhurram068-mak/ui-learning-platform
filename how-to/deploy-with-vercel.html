Deployment Guide

⚡ How to Deploy with Vercel

Updated October 2026 · 5 min read · Free hosting for static sites and frameworks

To deploy a website on Vercel, push your code to GitHub, connect the repo to Vercel, and click Deploy. Vercel handles HTTPS, CDN, and continuous deployment automatically. Every future push to your main branch updates the live site within 30 seconds.

Why Vercel: Free forever for personal projects, global CDN included, zero-config HTTPS, and it builds every framework out of the box — React, Next.js, Vue, Svelte, Astro, plain HTML.

What You Need

  • A GitHub account (free)
  • A Vercel account (free, sign up with GitHub)
  • Your project files (any HTML/CSS/JS, React, Next.js, or other framework)

Step-by-Step Deployment

Step 1
Push your project to GitHub

In your project folder, run:

$ git init $ git add . $ git commit -m "Initial commit" $ git branch -M main $ git remote add origin https://github.com/USERNAME/REPO.git $ git push -u origin main
Step 2
Sign up at Vercel

Go to vercel.com and click Sign Up. Choose "Continue with GitHub" — this authorises Vercel to access your repos.

Step 3
Import your repository

From the Vercel dashboard, click Add New → Project. You'll see a list of your GitHub repos. Find the one you want to deploy and click Import.

Step 4
Configure (or leave defaults)

Vercel auto-detects your framework. For plain HTML sites, leave everything default. For React/Next.js, it fills in the build command. Click Deploy.

Step 5
Done — your site is live

Within 30 seconds, Vercel gives you a URL like your-project.vercel.app. Open it — your site is running on the global edge network.

Automatic Deploys from Git

Once connected, every push to your main branch triggers a production deploy. Every pull request gets its own preview URL — perfect for review before merging.

# Push a change $ git add . $ git commit -m "Update hero section" $ git push # Vercel auto-deploys in ~30 seconds

Adding a Custom Domain

Any domain works with Vercel. In your project dashboard:

  1. Go to Settings → Domains
  2. Click Add and enter your domain (e.g., mydomain.com)
  3. Vercel shows you DNS records to add at your registrar
  4. Add them, wait 5–60 minutes for propagation
  5. Vercel auto-issues an SSL certificate

Free domain option: You can buy cheap domains ($1–12/year) at Namecheap, Porkbun, or Cloudflare. Or use free domain services like Freenom (limited).

Environment Variables

If your app uses API keys (Stripe, OpenAI, etc.), don't put them in your code. Add them to Vercel:

  1. Project → Settings → Environment Variables
  2. Add each key with its value
  3. Rebuild by pushing a new commit

Access them in your code:

// In Next.js API routes const apiKey = process.env.MY_API_KEY; // In frontend code (only variables prefixed with NEXT_PUBLIC_) const url = process.env.NEXT_PUBLIC_API_URL;

Vercel Free Plan Limits

  • 100 GB bandwidth per month — plenty for personal sites
  • Unlimited deployments
  • Global CDN in 100+ locations
  • Custom domains with free SSL
  • Serverless functions — 100 GB-hours per month
  • Non-commercial use only on the Hobby tier

Commercial projects: If your site makes money (ads, sales, subscriptions), you need the Pro plan ($20/month) per Vercel's terms.

Vercel vs Netlify vs Cloudflare Pages

  • Vercel — best for Next.js and React. Fastest builds, best DX.
  • Netlify — best for static sites and JAMstack. Excellent form handling.
  • Cloudflare Pages — best for cost-effective high-bandwidth sites. Free plan has unlimited bandwidth.

All three are free for personal projects. Pick one, learn it well, and deploy everything.

Troubleshooting

Build fails on Vercel but works locally

Usually a missing dependency or case-sensitive file path (Vercel's Linux build is case-sensitive; macOS/Windows are not). Check your imports and package.json.

404 on a route that works locally

Vercel is a static host. Client-side routing (React Router, Vue Router) needs a rewrite rule. Add a vercel.json:

{ "rewrites": [ { "source": "/(.*)", "destination": "/index.html" } ] }

Slow first load

The first visit after inactivity may hit a cold start. Vercel keeps functions warm on paid plans. For static sites, there's no cold start at all.

Frequently Asked Questions

Is Vercel free?

Yes for personal projects — unlimited deployments, 100 GB bandwidth, custom domains, and SSL. Commercial use requires Pro ($20/mo).

What can I deploy on Vercel?

Static sites, React, Vue, Svelte, Next.js, Nuxt, Astro, and any framework that outputs static files or supports serverless functions.

Do I need a custom domain?

No. Vercel gives you a free subdomain like your-project.vercel.app. Custom domains are optional but recommended for professional projects.

How do automatic deploys work?

Connect your GitHub repo. Every push to main deploys to production. Every PR gets its own preview URL.

Vercel vs Netlify — which is better?

Both are excellent and free. Vercel is best for Next.js and React. Netlify is best for static sites. Choose either — the workflow is nearly identical.
