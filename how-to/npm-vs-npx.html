npm vs npx vs yarn vs pnpm

Four tools, one job — managing JavaScript packages. Here's what each does, which to use, and when.

Quick answer: Use npm by default. Use pnpm for monorepos and disk-efficient installs. Use npx for one-off tools without installing. Use yarn only if your project already uses it.

⚡ The Real Difference

They're not all the same thing:

  • npm — the default package manager. Ships with Node.js.
  • npx — a runner. Executes packages without installing them globally.
  • yarn — an alternative package manager by Facebook (now independent).
  • pnpm — a package manager that uses hard links to save disk space.

🎯 When to Use Which

Use npm if:

  • You're starting any project and want zero setup
  • You want to use what everyone else uses (most tutorials)
  • You're learning — start with npm

Use pnpm if:

  • You work on a monorepo
  • You have many projects and want to save disk space
  • You want the fastest installs
  • You use Next.js, Vite, or Astro (they support pnpm well)

Use npx if:

  • You want to run a CLI tool once without installing it
  • You're using scaffolding tools like create-react-app, create-vite, create-next-app
  • You want to try a package before adding it to your project

Use yarn if:

  • Your project already uses yarn
  • You rely on Yarn Workspaces with legacy configs
  • You're maintaining a project built on Yarn 1.x

📚 Same Task, All Four Tools

# Install all dependencies
npm install              →  yarn              →  pnpm install
npx (not applicable)

# Add a package
npm install react        →  yarn add react    →  pnpm add react
npx (not applicable)

# Remove a package
npm uninstall lodash     →  yarn remove lodash →  pnpm remove lodash

# Run a script
npm run dev              →  yarn dev          →  pnpm dev

# Run a one-off CLI tool
npx create-next-app      →  yarn dlx          →  pnpm dlx
npx is specifically for this

❓ Frequently Asked Questions

What is the difference between npm and npx?

npm installs packages. npx runs packages without permanently installing them.

Is pnpm better than npm?

For monorepos and large projects, yes — faster and less disk. For solo projects, the difference is minor.

Should I use yarn or npm?

npm has caught up. For new projects, use npm or pnpm. Yarn is fine if you already use it.

Can I mix package managers?

No — don't mix within one project. Different lockfiles cause conflicts. Pick one per project.
