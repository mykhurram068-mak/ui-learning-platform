📐 How to Calculate Percentage Difference

Updated October 2026 · 5 min read · Includes formula and examples

To calculate percentage difference, subtract one value from the other, take the absolute value, divide by the average of the two values, then multiply by 100. The result is always positive and shows how far apart two numbers are as a percentage of their average.

Unlike percentage change, percentage difference doesn't care which value came first — it measures the gap between two numbers without assuming either is "original" or "new."

The Percentage Difference Formula

The Formula
% Difference = (|A − B| ÷ ((A + B) ÷ 2)) × 100

Three steps:

  1. Find the absolute difference: |A − B| (always positive)
  2. Find the average: (A + B) ÷ 2
  3. Divide and multiply: (difference ÷ average) × 100

Example 1: Comparing Prices

A laptop costs $900 at one store and $1,100 at another. What's the percentage difference?

Worked Example
Step 1: |900 − 1100| = 200
Step 2: (900 + 1100) ÷ 2 = 1000
Step 3: (200 ÷ 1000) × 100 = 20%
→ 20% difference between the two prices

Example 2: Comparing Test Scores

Two students score 72 and 88 on the same exam. What's the percentage difference?

Worked Example
Step 1: |72 − 88| = 16
Step 2: (72 + 88) ÷ 2 = 80
Step 3: (16 ÷ 80) × 100 = 20%
→ 20% difference between the two scores

Example 3: Comparing Measurements

A recipe yields 350 g of dough in one attempt and 410 g in another. What's the percentage difference?

Worked Example
Step 1: |350 − 410| = 60
Step 2: (350 + 410) ÷ 2 = 380
Step 3: (60 ÷ 380) × 100 = 15.79%
→ 15.79% difference

Percentage Difference vs. Percentage Change

These two terms sound similar but mean different things. Here's the distinction:

  • Percentage change — compares a new value to an original value. Order matters. Can be positive (increase) or negative (decrease). Formula: ((new − old) ÷ old) × 100.
  • Percentage difference — compares two values with no assumed order. Always positive. Uses the average of the two values as the base. Formula: (|A − B| ÷ ((A + B) ÷ 2)) × 100.

Rule of thumb: Use percentage change when there's a clear "before and after." Use percentage difference when comparing two things side by side.

Same Numbers, Different Answers

Here's the same pair of numbers calculated both ways:

  • Value A = 80, Value B = 100
  • Percentage change (80 → 100) = +25%
  • Percentage difference = (20 ÷ 90) × 100 = 22.22%

The change is 25% because it uses 80 as the base. The difference is 22.22% because it uses 90 (the average) as the base. Which one you want depends on your context.

When to Use Percentage Difference

  • Comparing prices of the same product at different stores
  • Comparing test scores or measurements between two samples
  • Comparing statistics between two countries or years (without order)
  • Comparing experimental results to control results
  • Comparing the same metric across two different time periods with no assumed direction

Common Mistakes to Avoid

  • Forgetting absolute value. Without it, the result can be negative — but percentage difference is always positive by definition.
  • Using the wrong base. Percentage difference uses the average, not the original value. If you used the original, you'd be calculating percentage change.
  • Dividing by the sum instead of the average. The correct formula is (A + B) ÷ 2, not A + B. Forgetting the ÷2 doubles your denominator and halves the result.
  • Confusing it with percentage error. Percentage error compares an experimental value to a theoretical value; percentage difference compares two values without a "true" reference.

Sanity check: If two values are far apart, the percentage difference will be large. If they're close, it'll be small. If either value is zero, the result becomes tricky — percentage difference isn't meaningful when one value is 0.

Reverse: Finding a Value from Percentage Difference

If you know one value and the percentage difference, you can work backward — but there are two answers (higher or lower), because percentage difference is symmetric. Solve:

Reverse Formula
B = A × ((200 ± d) ÷ (200 ∓ d))
where d is the percentage difference

This is rarely needed in practice. It's simpler to just use a calculator.

Frequently Asked Questions

What is the formula for percentage difference?

|A − B| ÷ ((A + B) ÷ 2) × 100. It uses the average of the two values as the base.

What's the difference between percentage difference and percentage change?

Percentage change compares a new value to an original value and can be negative. Percentage difference compares two values symmetrically, always positive, using their average as the base.

Can percentage difference be negative?

No. The absolute value makes it always positive. If direction matters, use percentage change.

When should I use percentage difference?

When comparing two values that don't have a clear "before and after" — prices at two stores, scores between two students, measurements between two samples.

Does order matter in percentage difference?

No. Percentage difference between 20 and 30 is identical to the difference between 30 and 20. This is different from percentage change, where order matters.

What if one value is zero?

Percentage difference isn't meaningful when one value is zero — the average becomes half the non-zero value, and the "difference" is the entire value, giving 200%. This is why percentage difference assumes both values are positive and non-zero.

How is percentage difference different from percentage error?

Percentage error compares an experimental value to a known "true" value. Percentage difference compares two values that are both measurements, with no truth claim. Both are positive, but the denominators differ.
