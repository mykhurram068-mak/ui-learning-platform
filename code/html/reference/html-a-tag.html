<a> — The Anchor Element

The tag that made the web a web. Creates hyperlinks to pages, files, and locations.

Last updated: October 2026

Definition: The <a> element (anchor) defines a hyperlink — the core of the World Wide Web. It can link to external pages, internal routes, files, email addresses, phone numbers, or specific locations inside a page.

🎬 Live Example

The anchor element in action. Every link below uses only HTML attributes — no JavaScript.

External link (opens new tab) → Jump to section on this page (#example-anchor) → Email link (mailto:) → Phone link (tel:) → Internal link (relative path) →

💡 Notice how the same element handles every kind of link. The behavior is controlled entirely by the href attribute.

📝 Basic Syntax

<a href="destination">Link text</a>

The href attribute is the only required attribute. Without it, the <a> is just text.

⚙️ Attributes Reference

Attribute Value Purpose
href URL The destination. Required.
target _self (default), _blank, _parent, _top Where to open the link.
rel noopener, noreferrer, nofollow, sponsored Relationship to destination.
download filename (optional) Download the target instead of navigating.
hreflang language code (e.g., es) Language of the linked resource.
type MIME type Expected MIME type of the target.
title text Tooltip text on hover.
ping URL list URLs to ping when the link is clicked (analytics).
referrerpolicy no-referrer, origin, etc. How much referrer info to send.
1

Basic External Link

Links to a page on another site. Always add rel="noopener noreferrer" when using target="_blank".

<a href="https://example.com" target="_blank" rel="noopener noreferrer">
    Visit Example
</a>
2

Internal Link (Relative Path)

Links to another page on the same site. Use paths relative to the current page or absolute paths starting with /.

<!-- Relative -->
<a href="./about.html">About Us</a>

<!-- Root-relative -->
<a href="/courses/python/">Python Course</a>
3

Fragment Link (Jump to Section)

Links to a specific element on the same page or another page. The #id matches the id attribute of the target.

<!-- Link to a section on this page -->
<a href="#attributes">Jump to Attributes</a>

<!-- The target -->
<h2 id="attributes">Attributes</h2>

<!-- Link to a section on another page -->
<a href="/docs/api.html#authentication">API Auth</a>
4

Email and Phone Links

Opens the user's email client or phone dialer. No JavaScript required.

<!-- Email with subject and body -->
<a href="mailto:hello@example.com?subject=Hello&body=Hi there">
    Send Email
</a>

<!-- Phone (uses device dialer on mobile) -->
<a href="tel:+15551234567">Call Us</a>

<!-- SMS -->
<a href="sms:+15551234567">Send Text</a>
5

Downloadable Files

The download attribute tells the browser to download the linked file instead of navigating to it.

<!-- Downloads the file -->
<a href="/files/guide.pdf" download>Download PDF</a>

<!-- Downloads and renames the file -->
<a href="/files/guide.pdf" download="html-guide.pdf">
    Download HTML Guide
</a>

💡 Note: download only works for same-origin URLs. Cross-origin downloads are blocked by browsers for security.

6

SEO Attributes — rel="nofollow" and rel="sponsored"

Tell search engines how to treat the link.

<!-- Don't pass SEO value to this link -->
<a href="https://unknown-site.com" rel="nofollow">
    Unverified Site
</a>

<!-- This is a paid or sponsored link -->
<a href="https://advertiser.com" rel="sponsored">
    Sponsored Link
</a>

<!-- Multiple values are allowed -->
<a href="https://example.com" rel="noopener noreferrer nofollow">
    External Link
</a>

🎯 Attribute Values Cheatsheet

target value Behavior
_self Opens in the same tab (default).
_blank Opens in a new tab or window.
_parent Opens in the parent frame (for iframes).
_top Opens in the topmost frame, exiting all iframes.
rel value Meaning
noopener Prevents the linked page from accessing window.opener.
noreferrer Don't send the referrer header. Implies noopener.
nofollow Don't pass SEO link juice. Use for untrusted links.
sponsored This is a paid/sponsored link.
ugc User-generated content (comments, forums).

⚠️ Common Mistakes

  • Using target="_blank" without rel="noopener". This creates a security hole where the linked page can redirect your original tab. Modern browsers auto-add noopener, but always include it explicitly.
  • Using "click here" as link text. Bad for SEO and accessibility. Screen readers announce link text out of context — "click here" tells the user nothing. Use descriptive text: "Read the HTML guide."
  • Nesting interactive elements inside <a>. Do not put buttons, other links, or inputs inside an anchor. It breaks keyboard navigation and produces invalid HTML.
  • Using javascript:void(0) for links that do nothing. Use a <button> instead. Anchors are for navigation.
  • Missing href. An anchor without href is not keyboard focusable. If you need a clickable element that isn't navigation, use a button.
  • Forgetting that download requires same-origin. Cross-origin downloads are blocked. If you need cross-origin downloads, proxy the file through your own server.

♿ Accessibility Notes

  • Every anchor should have descriptive link text. Avoid "click here" or "read more."
  • If the link text alone isn't descriptive (e.g., an icon-only link), add aria-label: <a href="/cart" aria-label="View cart">🛒</a>.
  • Anchors are focusable by default with the Tab key. Never remove the focus outline with outline: none unless you replace it with a visible alternative.
  • Use <a> for navigation only. Use <button> for actions that trigger JavaScript.
  • For links that open in a new tab, consider adding a visual indicator (like ↗) or aria-label that mentions "opens in a new tab."

❓ Frequently Asked Questions

What is the HTML <a> tag?

The <a> tag (anchor element) creates hyperlinks to other pages, files, locations within the same page, or any other URL. It is the defining feature of the World Wide Web.

What does the href attribute do?

The href (hypertext reference) attribute specifies the destination of the link. It can be a URL, an email address (mailto:), a phone number (tel:), a file download, or a fragment identifier (#section).

What is the difference between target="_blank" and target="_self"?

target="_blank" opens the link in a new tab or window. target="_self" opens it in the same tab (default). Always pair _blank with rel="noopener noreferrer" for security.

What does rel="noopener" do?

rel="noopener" prevents the new page from accessing the window.opener property of your page. This closes a security hole where the linked page could redirect your original tab to a phishing site.

How do I make an email link in HTML?

Use href="mailto:email@example.com". This opens the user's default email client with the address pre-filled. You can add subject and body with query parameters: mailto:email@example.com?subject=Hello&body=Hi.
