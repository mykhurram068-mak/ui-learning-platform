<a> — The Anchor Element

The tag that made the web a web. Creates hyperlinks to pages, files, and locations.

Last updated: October 2026

Definition: The <a> element (anchor) defines a hyperlink — the core of the World Wide Web. It can link to external pages, internal routes, files, email addresses, phone numbers, or specific locations inside a page.

🎬 Live Example

Every link below uses only HTML attributes — no JavaScript.

💡 Notice how the same element handles every kind of link. Behavior is controlled by the href attribute.

📝 Basic Syntax

<a href="destination">Link text</a>

The href attribute is the only required attribute.

⚠️ Common Mistakes

  • Using target="_blank" without rel="noopener". Security hole — the linked page can redirect your original tab.
  • Using "click here" as link text. Bad for SEO and accessibility.
  • Nesting interactive elements inside <a>. Breaks keyboard navigation.
  • Using javascript:void(0). Use a <button> instead.
  • Missing href. Without it, the anchor isn't keyboard focusable.

♿ Accessibility Notes

  • Every anchor needs descriptive link text. Avoid "click here."
  • For icon-only links, add aria-label.
  • Anchors are focusable by default. Don't remove the focus outline without a visible alternative.
  • Use <a> for navigation only. Use <button> for actions.

❓ Frequently Asked Questions

What is the HTML <a> tag?

The <a> tag creates hyperlinks to other pages, files, locations within the same page, or any other URL. It is the defining feature of the World Wide Web.

What does the href attribute do?

The href attribute specifies the destination of the link. It can be a URL, an email address (mailto:), a phone number (tel:), a file download, or a fragment identifier (#section).

What does rel="noopener" do?

It prevents the new page from accessing the window.opener property of your page, closing a security hole.

How do I make an email link?

Use href="mailto:email@example.com". Add subject with ?subject=Hello.
