len()

Return the number of items in a sequence. Works on strings, lists, dicts, and more.

Last updated: October 2026

Definition: len() returns the number of items in an object. It works on strings, lists, tuples, dicts, sets, and any object that implements the __len__() method.

Basic Syntax

                    
len(s)

# s — any object with a __len__() method
# Returns: int (number of items)
# Raises: TypeError if object has no length

List and Tuple Length

                    
len([1, 2, 3])              # 3
len([])                     # 0
len([1, [2, 3], 4])         # 3 (nested list counts as 1)
len((1, 2, 3))              # 3

                    

                        
Pro tip: len() does not count nested items — a list containing a list has length 2, not 3+.

items = list(range(100))

    return page * page_size < len(items)

⚠️ Common Mistakes

            
    
                
  • Calling len on integers. Raises TypeError. Convert with str() first.
    • 
                
  • Thinking len counts nested items. It counts top-level only.
    • 
                
  • Comparing to [] or "" for empty. Use if not items instead.
    • 
                
  • Using len in a loop to iterate. Iterate directly — for x in items.
    • 
                
  • Assuming len returns float. It always returns int.

❓ Frequently Asked Questions

            

                

                    What does len() do in Python?
                    
len() returns the number of items in an object. It works on strings, lists, tuples, dicts, sets, and any object that implements __len__().

                

                

                    Does len() work on numbers?
                    
No. len() raises TypeError on int, float, and complex numbers because they have no length. Convert to a string first: len(str(42)).

                

                

                    How does len() work on strings?
                    
len() returns the number of Unicode code points (characters) in the string. Emojis count as multiple code points in some cases.

                

                

                    How does len() work on dicts?
                    
len() returns the number of key-value pairs. A dict with 3 keys has len() == 3, regardless of key or value sizes.

                

                

                    Is len() O(1) or O(n)?
                    
len() is O(1) for all built-in types. Python stores length internally, so it just reads a cached value.
