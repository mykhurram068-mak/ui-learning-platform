📖 How to use these prompts

1
Pick your category

Debugging when stuck. Refactoring before merging. Code Review before shipping. Architecture before building.

2
Copy the prompt exactly

Each prompt includes [bracketed] placeholders. Fill them in, paste into Claude Code, Cursor, or Copilot Chat.

3
Read every line of output

AI generates plausible code, not always correct code. Never merge what you don't understand.

4
Iterate with the "why"

If the output is close but not right, add: "Explain your reasoning for each change." This usually fixes it on the second try.

🎯 The five principles behind every prompt here

  • Context before task. What's the file? What framework? What version? AI works better with a scene.
  • Specific, not vague. "Fix this bug" gives vague fixes. "Find the root cause of this null access in the auth flow" gives real answers.
  • Constraints included. Style, dependencies, patterns — tell AI the rules upfront.
  • Format expected. Function, class, file, test, comment — say what shape you want back.
  • Verification required. Every debugging prompt ends with "verify the fix by X". This catches hallucinations early.

❓ Frequently asked questions

Which AI tool do these prompts work with?

All of them. Every prompt works in Claude Code, Cursor, GitHub Copilot Chat, ChatGPT, and Claude.ai. The prompts don't rely on tool-specific syntax.

Are these prompts free to use?

Yes. Copy them, paste them, adapt them, share them. No attribution required. We only ask that you don't republish the entire library as your own product.

How often is the library updated?

Every month. New prompts get added as AI tools evolve. The four categories are stable, but individual prompts are added, refined, and occasionally retired.

Can I submit my own prompts?

Yes. Contact us with the prompt, what it does, and the tool you use. We review submissions and add the best ones to the library.

Do longer prompts always work better?

No. The best prompts are short and specific. Length helps only when it adds real context — not padding. Every prompt in this library is under 150 words for a reason.
