width & height

Controls the dimensions of an element. The foundation of every layout decision.

Last updated: October 2026

Definition: The width and height properties set the dimensions of an element's content box. By default, padding and border add to these dimensions. Setting box-sizing: border-box includes them inside the declared size.

Basic Syntax

.box {
    width: 300px;
    height: 200px;
}

.responsive {
    max-width: 800px;  /* Never wider than 800px */
    width: 100%;       /* Fills parent if narrower */
}

1

width vs max-width — The Responsive Rule

Prefer max-width over width for responsive design.

/* ❌ Fixed width — breaks on mobile */
.container {
    width: 800px;
}

/* ✅ Responsive — shrinks on mobile */
.container {
    width: 100%;
    max-width: 800px;
    margin: 0 auto;
}

The responsive version fills its parent on mobile, caps at 800px on desktop, and centers with margin: 0 auto.

3

box-sizing — The Layout Saver

The single most impactful CSS rule for predictable layouts.

/* The universal reset — put this at the top of every stylesheet */
*,
*::before,
*::after {
    box-sizing: border-box;
}

/* Now width includes padding and border */
.card {
    width: 300px;
    padding: 20px;
    border: 2px solid;
    /* Total width: 300px (not 344px) */
}

Without border-box, an element with width: 300px; padding: 20px; border: 2px would actually be 344px wide. This breaks layouts.

4

Full-Height Sections

Making sections fill the viewport height correctly is trickier than it looks.

/* Classic: fills viewport height */
.hero {
    min-height: 100vh;
}

/* Modern: handles mobile browser UI correctly */
.hero {
    min-height: 100dvh;  /* dvh = dynamic viewport height */
}

/* Full-screen layout with header and footer */
.layout {
    display: grid;
    grid-template-rows: auto 1fr auto;
    min-height: 100vh;
}

💡 Why dvh? On mobile, 100vh includes the browser address bar even when it's hidden, causing content to be cut off. 100dvh adjusts dynamically. Supported in all modern browsers since 2022.

5

aspect-ratio — Fixed Proportions

/* 16:9 video container */
.video {
    aspect-ratio: 16 / 9;
    width: 100%;
}

/* Square avatar */
.avatar {
    aspect-ratio: 1;
    width: 60px;
}

/* Card with consistent proportions */
.card-image {
    aspect-ratio: 4 / 3;
    object-fit: cover;
    width: 100%;
}

aspect-ratio is the modern replacement for the padding-top hack that developers used to force fixed aspect ratios.

⚠️ Common Mistakes

  • Using fixed width instead of max-width. Breaks on mobile — always use max-width for responsive containers.
  • Forgetting box-sizing: border-box. Padding and border add to the size, breaking layouts.
  • Using height: 100% without a parent height. Percentage heights need a defined parent height, or they collapse to 0.
  • Using 100vw for full width. 100vw includes the scrollbar width and can cause horizontal overflow. Use width: 100% on a full-width parent instead.
  • Not testing width on 320px viewports. Some layouts look fine at 375px and break at 320px. Test the smallest phone size.
  • Height on inline elements. Width and height don't apply to display: inline elements. Use inline-block or block.
  • Setting both width and height on text-heavy elements. Text needs to grow. Use min-height instead.

♿ Accessibility Notes

  • Never lock heights on text containers. Users with larger fonts need content to grow. Use min-height instead.
  • Support 200% zoom. Widths in px may not scale with zoom. Use rem or % where possible.
  • Full-viewport heights can hide content. Users who zoom in see less of the viewport. Ensure critical content isn't off-screen.
  • Touch targets need minimum width/height. Aim for at least 44×44px for buttons and links (WCAG 2.5.5).
  • Respect 100dvh for mobile. Using 100vh on mobile can hide content behind the address bar.

❓ Frequently Asked Questions

What is the CSS width property?

The width property sets the horizontal size of an element's content box. It accepts fixed units (px), relative units (%), viewport units (vw), and keywords (auto, fit-content, max-content). It does not include padding, border, or margin unless box-sizing: border-box is set.

What is the difference between width and max-width?

width sets an exact size. max-width sets a limit — the element can be smaller but never larger. Using max-width instead of width is the responsive best practice because it lets content shrink on small screens.

What is box-sizing: border-box?

box-sizing: border-box changes the box model so padding and border are included inside the declared width. This makes layouts predictable — an element with width: 100px and padding: 20px stays exactly 100px wide instead of becoming 140px.

What is the difference between 100vw and 100%?

100vw is always the full viewport width, including the scrollbar. 100% is 100% of the parent element's width, which is usually safer because it accounts for scrollbars and containers.

What is aspect-ratio in CSS?

aspect-ratio lets you set the ratio between an element's width and height. Example: aspect-ratio: 16 / 9 keeps a video container in widescreen proportion regardless of its actual size.
