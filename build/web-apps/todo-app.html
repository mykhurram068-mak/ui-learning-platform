Build a To-Do App

Vanilla HTML, CSS, and JavaScript. Persists with localStorage. No frameworks, no build step, no dependencies.

⏱️ 45 minutes · 📄 3 files · 🎯 Beginner

What you'll build: A to-do app where you can add tasks, mark them complete, and delete them. Everything saves automatically to your browser — reload the page, and your tasks are still there.

What you'll learn: DOM manipulation, event handling, state management, rendering from data, and localStorage. These four skills power every modern web app.

index.html — the structure

Why so little HTML? In a real app, JavaScript builds most of the UI from data. You render the structure once, then update it as state changes.

app.js — the behavior

This is where everything happens. Three functions: render(), addTask(), and a small save/load pair for localStorage.

app.js 
// State — the single source of truth
let tasks = [];

// Grab DOM elements once
const input = document.getElementById('taskInput');
const addBtn = document.getElementById('addBtn');
const list = document.getElementById('taskList');
const counter = document.getElementById('counter');

// ============ STORAGE ============
function save() {
  localStorage.setItem('tasks', JSON.stringify(tasks));
}

function load() {
  const stored = localStorage.getItem('tasks');
  if (stored) tasks = JSON.parse(stored);
}

// ============ RENDER ============
function render() {
  list.innerHTML = '';

  if (tasks.length === 0) {
    list.innerHTML = '<div class="empty">No tasks yet. Add one above.</div>';
  } else {
    tasks.forEach(task => {
      const row = document.createElement('div');
      row.className = 'task' + (task.done ? ' done' : '');

      const check = document.createElement('input');
      check.type = 'checkbox';
      check.checked = task.done;
      check.addEventListener('change', () => {
        task.done = !task.done;
        save();
        render();
      });

      const text = document.createElement('span');
      text.className = 'task-text';
      text.textContent = task.text;

      const del = document.createElement('button');
      del.className = 'delete-btn';
      del.textContent = '✕';
      del.addEventListener('click', () => {
        tasks = tasks.filter(t => t.id !== task.id);
        save();
        render();
      });

      row.append(check, text, del);
      list.appendChild(row);
    });
  }

  const remaining = tasks.filter(t => !t.done).length;
  counter.textContent = `${remaining} of ${tasks.length} tasks remaining`;
}

// ============ ADD ============
function addTask() {
  const text = input.value.trim();
  if (!text) return;

  tasks.push({
    id: Date.now(),
    text,
    done: false
  });

  input.value = '';
  save();
  render();
}

// ============ EVENTS ============
addBtn.addEventListener('click', addTask);
input.addEventListener('keydown', e => {
  if (e.key === 'Enter') addTask();
});

// ============ INIT ============
load();
render();

How the code works

The pattern behind this app is state → render → save. Every action follows the same three steps:

1. The state is a single array

tasks holds every task as an object: {id, text, done}. Nothing else stores task data — the array is the truth.

2. The UI is derived from state

Every time state changes, render() clears the list and rebuilds it from tasks. No partial updates, no bugs from stale DOM.

3. State is persisted after every change

save() writes the array to localStorage as JSON. On page load, load() reads it back. That's the entire persistence layer.

⚠️ Common problems

Tasks disappear on reload

You forgot to call save() after mutating tasks, or you didn't call load() on startup. Check that localStorage.setItem('tasks', ...) is present in save().

Cannot read property 'appendChild' of null

The script runs before the DOM is ready. Either move <script> to the end of <body>, or wrap the init code in DOMContentLoaded.

Checkbox doesn't toggle

You probably mutated task.done without calling render(). The DOM won't update on its own — you have to re-render.

Deleting removes the wrong task

Classic closure bug — you likely used a loop index instead of the task ID. This tutorial uses task.id specifically to avoid that issue.

🎯 What to add next

  • Edit existing tasks. Double-click the text, swap in an input, save on blur.
  • Filter by status. All / Active / Completed tabs that change what renders.
  • Clear completed. One button that filters out task.done === true.
  • Drag to reorder. Use the HTML5 drag-and-drop API to reshuffle tasks.
  • Add a backend. Replace localStorage with a fetch to an API (Node + Express or Firebase).
  • Add categories. Give each task a tags array and filter on that.

❓ Frequently asked questions

What will I learn building a to-do app?

You'll learn DOM manipulation, event handling, state management with a JavaScript array, rendering UI from data, and persisting state with localStorage. These are the four skills behind every modern web app.

How long does this build take?

About 45 minutes if you copy-paste and run it. About 2 hours if you type every line and follow each explanation. Both are valid — the second sticks better.

Do I need to install anything?

No. This build runs entirely in your browser. You need a text editor and a browser. No Node.js, no npm, no build tools.

Why use localStorage instead of a database?

localStorage is perfect for a first project because it requires zero setup. The data persists between page reloads and lives in the user's browser. Once you're comfortable, you can add a backend later.

How do I deploy this app?

Drag the folder to Netlify Drop or push it to GitHub and enable GitHub Pages. Both are free and give you a live URL in under 5 minutes.
