❓ Frequently asked questions

Are these tutorials really complete?

Yes. Every build includes the full working code. You can copy-paste and run it in minutes, or follow along step by step to understand it. Nothing is left as "an exercise for the reader."

What if I get stuck?

Each tutorial has a "common problems" section at the bottom with the errors people actually hit. If something else breaks, message us and we'll add it to the tutorial.

Do I need to install anything?

Web app projects run in your browser — nothing to install. Desktop app projects (Electron, Tauri) require Node.js or Rust. Each tutorial lists what you need upfront.

Can I use these in my portfolio?

Yes. Build it, tweak it, add your own features, deploy it, and put it in your portfolio. Attribution isn't required — but we love seeing what people build.
