How to Submit Your Project

  1. Complete any lesson project — the bio page or calculator are great first choices.
  2. Deploy your project for free using our GitHub Pages guide.
  3. Fill out the submission form with your project link and a short description.
  4. Your project appears on this page within 48 hours.

Submissions are free. No signup required. We accept any project that used a MAK Studio lesson as a starting point.
