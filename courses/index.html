❓ Frequently asked questions

Are these programming courses really free?

Yes. Every lesson, every code example, every project is free. No signup, no email gate, no paywall, no ads. The site is built as a free alternative to gated coding courses.

Which language should I start with?

HTML first, then CSS, then JavaScript, then Python, then AI. HTML is structure, CSS is styling, JavaScript is behavior, Python is server-side, and AI builds on Python. Learning them in this order means every new language builds on the previous one.

Do I need to install anything to start?

For HTML, CSS, and JavaScript: no. You need a text editor and a browser, both of which you already have. For Python: you need to install Python, which our setup guide covers in 10 minutes. For AI: Python plus a few packages installed through pip.

How long does each course take?

HTML takes 3 weeks at 1 hour a day. CSS takes 6 weeks. JavaScript takes 8 weeks. Python takes 8 weeks. AI is still being built. Each is self-paced — you can go faster or slower. The estimate is based on someone starting from zero.

Will there be more courses?

Yes. SQL is planned for later in 2026. React and additional advanced lessons are also planned. The current focus is completing the CSS and AI tracks so all five announced courses are fully built out.

Do I need to know a language before the next course?

For HTML, no — start there. For CSS, you need HTML. For JavaScript, you need HTML and CSS. For Python, no prerequisites — but knowing another programming language makes it easier. For AI, you need Python.
