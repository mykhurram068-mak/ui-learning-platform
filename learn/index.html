❓ Frequently asked questions

Are these learning paths really free?

Yes. Every path, every reference page, every snippet is free. No signup, no paywall, no course upsell. The only cost is your time and internet connection.

Do I need to pay for tools or subscriptions?

No. Python, JavaScript, HTML, and CSS are all free. For AI-assisted coding, GitHub Copilot has a free tier, and you can start learning with that. Paid tools are optional upgrades, not requirements.

Can I follow more than one path at a time?

We strongly recommend one at a time. Focus beats volume every time. Finish one path's project, then start the next.

Which path leads to a job fastest?

Web Development, if you finish all 8 steps and build the three portfolio projects. That's roughly 4–6 months of consistent work and it's the most direct path to junior developer roles.

How long is each step?

Steps range from 3 days to 3 weeks depending on the topic. The "Realistic Timeline" table at the bottom of each path gives exact estimates.

Will there be more paths?

Yes. Planned additions include TypeScript, React, Node.js, and data science. The current four cover the most in-demand skills for 2026.
